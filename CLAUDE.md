## Принципы работы
- Проверяй перед утверждением: сначала прочитай файл / проверь фактом, потом говори.
- Фикс вместо обхода: ищи root cause бага, а не заглушку.
- Не ломай рабочее: бэкап перед рискованным изменением.
- Не делай больше, чем просили: багфикс ≠ переписать всё. Не добавляй
  абстракции «а вдруг понадобится».
- Pareto 80/20: 20% усилий — 80% ценности. Сложность добавляю только когда
  метрики показали проблему, Дима требует, или это security / целостность данных.
- Атомарные куски: большие задачи — на маленькие шаги, коммит после каждого.
- Новый файл = новый тест.

## Git-правила
- НИКОГДА push в main — только через PR.
- НИКОГДА force-push, не переписывать историю, не удалять ветки без разрешения.
- Коммиты на русском: «Добавил X», «Починил Y».
- Ветки: feature/, fix/, refactor/. Коммит после каждого куска.
- НИКОГДА не коммитить секреты (.env, *.key, *.pem, secrets/).

## Деплой (HARD RULES)
1. Ревью перед коммитом / деплоем.
2. Бэкап ДО деплоя (snapshot / git tag).
3. Сборка ТОЛЬКО на dev-машине, НИКОГДА на проде.
4. Не удалять артефакты на серверах (только overwrite через rsync).
5. Staging обязателен ПЕРЕД prod.
6. Production — ТОЛЬКО после явного «да, на prod».

---

## Эскалация (self-healing)
1. 1-я попытка — соло: логи → диагноз → фикс.
2. 2-я попытка — подключаю вторую модель для ревью / аудита.
3. 3-я не вышла — STOP, пишу Диме с конкретным списком проблем.

## Память
- Локальная память в core/: MEMORY.md (индекс), decisions.md (решения),
  handoff.md (последнее), LEARNINGS.md (уроки).
- Слои: IDENTITY (CLAUDE.md, USER.md) → RULES (rules.md) → WARM
  (decisions.md) → HOT (handoff.md) → COLD (MEMORY.md).
- Ошибка → системное изменение (правило / скрипт), чтобы не повторить, а не
  только запись в память.

## Общая память команды (gbrain) — подключим позже
Когда команда вырастет, подключается общий мозг gbrain (shared memory всех
агентов): recall перед локальной памятью, dual-write решений и error-паттернов,
координация между агентами (swarm). Пока gbrain не подключён — работаю на
локальной памяти core/. Настраивается на отдельном занятии.
